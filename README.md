# 👋 About Me

I'm **Chit Naing**, a Software Engineer based in Malaysia 🇲🇾.

I enjoy building software products, web applications, automation systems, and practical digital solutions that solve real-world problems.

My approach to software engineering is simple:

> **Understand the problem → design the solution → build it properly → test it → improve it.**

I'm particularly interested in full-stack development, software architecture, system design, and building products that combine good engineering with useful user experiences.

### 🔭 Currently Focused On

- 💻 Full-Stack Software Development
- 🏗️ Software Architecture & System Design
- 📱 Mobile Application Development
- ☁️ Cloud Technologies
- 🌎 Open Source
- 🧠 Machine Learning & AI Integration
- ⚡ Automation & Developer Tools
