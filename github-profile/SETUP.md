# Install your GitHub profile design

1. Open your public profile repository `Chen-maker-pen/Chen-maker-pen` on GitHub. Create it with that exact name if needed.
2. Save a copy of your existing README.
3. Replace its root `README.md` with the supplied README.md, and upload the entire `assets` folder at the repository root.
4. Commit the files, then open your GitHub profile.

Keep README.md and assets/ together; pasting the README alone will leave missing images. You do not need to upload preview.html or SETUP.md.

## Design notes

Custom SVG illustrations use graphite (#171B1E), ivory (#F2EEE6), and copper (#CDA585). All artwork is local, editable vector artwork with no external fonts, trackers, animation services, or image servers. Project illustrations are conceptual artwork, not screenshots of the applications. Claims and technologies come from your supplied README; no metrics or credentials were invented. Existing destination links were preserved, but their availability was not independently verified.

preview.html is a local approximation with light/dark viewing controls. GitHub controls the surrounding typography, spacing, borders, and responsive table behavior; these cannot be fully customized by a profile README. Review the final result on GitHub, particularly on narrow screens. The hero remains dark in both themes by design.
